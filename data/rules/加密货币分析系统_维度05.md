# 加密货币分析系统｜维度 05

#### [维度 05] 趋势与均线

- **核心指标:** Trend（日线收盘、MA200、MA50、ADX(14)、+DI/−DI）100%。
- **数据源与窗口:** 先锁定目标交易对和UTC截止时间`as_of`；默认BTC时`symbol=BTCUSDT`。调用`getSpotKlineCandlestickData(symbol=目标交易对,interval=1d,limit=301,timeZone=0,endTime=预期最新完整日线收盘时间戳)`取得Binance现货原始数组。`endTime`取`as_of`所在UTC自然日00:00:00前1毫秒；用截至`as_of`最近300根完整UTC日线计算，侧重近1–3个月。
- **维度权重:** `dimension_weight = 0.25`。
- **评分规则 (0–10):** 按“长期准入→趋势择时→均线确认”顺序判定；阈值尚未回测。
  - 准入：收盘>MA200且MA200高于20日前。
  - 择时：ADX(14)>25且+DI>−DI。
  - 确认：MA50>MA200且MA50高于20日前。

| 条件 | 得分 |
|---|---:|
| 收盘 < MA200且MA200低于20日前 | 0 |
| 准入未通过，且不满足0分条件 | 2.5 |
| 准入通过、择时未通过 | 5 |
| 准入和择时通过、确认未通过 | 7.5 |
| 三层全部通过 | 10 |

- **计算口径:**
  - **输入核对：** 由大模型直接使用Action返回的原始K线数组，不调用Python脚本。每根K线至少包含开盘时间`openTime`、最高价`high`、最低价`low`、收盘价`close`和收盘时间`closeTime`，分别位于数组索引0、2、3、4、6。只纳入`closeTime<as_of`的K线，按`openTime`升序取最近300根。检查数值均有限且大于0、`high≥low`、`low≤close≤high`；每根须于UTC 00:00开盘，`closeTime=openTime+86,400,000−1`毫秒，相邻开盘时间相差86,400,000毫秒。Action失败、响应截断、完整日线不足300根、字段无效或日期缺口记`data_missing`，不得补造或缩短窗口。
  - **均线：** 将选中日线从旧到新编号为0–299，收盘价为`C[i]`。`MA_n(t)=ΣC[t−n+1..t]/n`；当前MA50、MA200取`t=299`，20日前MA50、MA200取`t=279`。用未舍入值比较当前值和20日前值的方向。
  - **Wilder ADX(14)：** 对`i=1..299`逐根计算`up=H[i]−H[i−1]`、`down=L[i−1]−L[i]`、`TR[i]=max(H[i]−L[i], |H[i]−C[i−1]|, |L[i]−C[i−1]|)`。当`up>down`且`up>0`时`+DM[i]=up`，否则为0；当`down>up`且`down>0`时`−DM[i]=down`，否则为0。索引14处的平滑TR、+DM、−DM分别为各自索引1至14的数值之和；从索引15起，每项平滑值按`前值−前值/14+当根值`递推。令`PDI=100×平滑+DM/平滑TR`、`MDI=100×平滑−DM/平滑TR`、`DX=100×|PDI−MDI|/(PDI+MDI)`；平滑TR为0时PDI、MDI、DX均记0，PDI+MDI为0时DX记0。首个ADX为`DX[14..27]`的算术平均，从索引28起按`ADX[i]=(13×ADX[i−1]+DX[i])/14`递推至索引299。最终使用索引299处的ADX、`+DI=PDI`、`−DI=MDI`评分。
  - **结果与分类：** 大模型必须基于完整原始数据逐项完成上述计算，保留数据起止时间、均线当前及20日前值、ADX/DI结果和关键中间值，内部核对命中规则；不得只凭最新收盘价、局部K线或图形印象估算。最新日线时效也通过时才报告得分。数据缺失或过期直接记`data_missing`，不重试计算。原始数据完整但计算失败或无法核对时，复用同一批已校验K线和已核对的中间结果，定位失败步骤并重新计算该步骤及其后续依赖，最多重试2次（首次计算加2次重试，共最多3次）；每次核对重算部分的中间值与最终指标，记录实际尝试次数及失败原因。任一次成功且结果可核对则正常评分；全部失败才记`calculation_error`。`data_missing`和最终`calculation_error`均为`score=null`、`confidence=0`，写明具体原因并继续其他维度，不得把缺失记为0分或声称已算出指标。
- **数据有效期:** 核对最新完整日线的`closeTime`等于`as_of`所在UTC自然日00:00:00前1毫秒；若不相等，维度状态记`data_missing`并说明“最新完整日线过期”，不采用其指标和得分。盘中价格注明时间，不参与评分。
