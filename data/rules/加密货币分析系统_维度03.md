# 加密货币分析系统｜维度 03

#### [维度 03] ETF资金流

- **核心指标:** ETF_Flows（目标资产现货ETF净资金流）100%。
- **数据源与窗口:** MCP get_asset_flows(asset=目标币种)；最近20个交易日，重点5日和最新单日。
- **维度权重:** `dimension_weight = 0.15`。
- **评分规则 (0–10):** BTC按方向与金额分档，不做线性插值；5分为中性。阈值未经回测，其他资产金额阈值尚未确认，不能直接套用BTC阈值。
- **综合评分:** `score = five_day_score × 0.4 + twenty_day_score × 0.6`。两个窗口存在重叠，此权重为组合规则，不代表窗口相互独立。

| 档位 | 5日累计净流量（百万美元） | 20日累计净流量（百万美元） | 强度分 |
|---|---|---|---:|
| 大幅流出 | ≤ -1500 | ≤ -5000 | 0 |
| 明显流出 | -1500 < 流量 < -500 | -5000 < 流量 < -1500 | 2.5 |
| 中性/小幅流动 | -500 ≤ 流量 ≤ 500 | -1500 ≤ 流量 ≤ 1500 | 5 |
| 明显流入 | 500 < 流量 < 1500 | 1500 < 流量 < 5000 | 7.5 |
| 大幅流入 | ≥ 1500 | ≥ 5000 | 10 |

- **计算示例:** 5日422.4百万美元得5分，20日3032.7百万美元得7.5分，综合6.5分；此为规则示例，不是实时数据。

- **计算口径:** 固定目标资产的现货ETF基金范围和交易日历，按交易日取美元净流量；5日、20日为最近对应交易日的合计，单日及此前不重叠5日只作辅助解释。休市不算缺失，应报未报不填0；不混入期货ETF、其他资产、成交额或AUM。5日与20日方向相反标conflict_flag。
- **数据有效期:** 覆盖截至`as_of`的最新完整交易日及20个交易日；以交易日和基金净流量完整性判断有效性，`updatedAt`即使晚于`as_of`也不影响评分；基金数据不全、缺日或口径不明则missing；无该资产现货ETF则N/A。
- **数据可信度:** 官方基金数据完整=1；可核验的完整汇总=0.75；来源存在实质不确定性但仍可核验并完整评分=0.5；数据缺失或无法核验=0。
