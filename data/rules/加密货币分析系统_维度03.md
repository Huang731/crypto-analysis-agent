# 加密货币分析系统｜维度 03

#### [维度 03] ETF资金流

- **核心指标:** ETF_Flows（目标资产现货ETF净资金流）100%。
- **数据源与窗口:** getCryptoEtfFlows(asset=目标币种)；最近20个交易日，重点5日和最新单日。
- **维度权重:** `dimension_weight = 0.15`。
- **评分规则 (0–10):** 由最近5日与20日净流量方向确定；阈值未经回测。

| 条件 | 得分 |
|---|---:|
| 5日<0且20日<0 | 0 |
| 5日<0且20日≥0，或5日=0且20日<0 | 2.5 |
| 5日=0且20日=0 | 5 |
| 5日>0且20日≤0，或5日=0且20日>0 | 7.5 |
| 5日>0且20日>0 | 10 |

- **计算口径:** 固定目标资产的现货ETF基金范围和交易日历，按交易日取美元净流量；5日、20日为最近对应交易日的合计，单日及此前不重叠5日只作辅助解释。休市不算缺失，应报未报不填0；不混入期货ETF、其他资产、成交额或AUM。5日与20日方向相反标conflict_flag。
- **数据有效期:** 覆盖截至`as_of`的最新完整交易日及20个交易日；以交易日和基金净流量完整性判断有效性，`updatedAt`即使晚于`as_of`也不影响评分；基金数据不全、缺日或口径不明则missing；无该资产现货ETF则N/A。
- **数据可信度:** 官方基金数据完整=1；可核验的完整汇总=0.75；来源存在实质不确定性但仍可核验并完整评分=0.5；数据缺失或无法核验=0。
