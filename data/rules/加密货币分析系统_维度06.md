# 加密货币分析系统｜维度 06

#### [维度 06] 市场情绪

- **核心指标:** Fear_Greed（恐惧与贪婪指数）100%。
- **数据源与窗口:** CMC API `/v3/fear-and-greed/latest`；使用截至`as_of`的最新合格记录。
- **维度权重:** `dimension_weight = 0.15`。
- **评分规则 (0–10):** 按恐惧与贪婪指数分档评分，阈值尚未回测。

| 指数区间 | 得分 | 信号参考 |
|---|---:|---|
| 0–19 | 5 | 买入区域 |
| 20–39 | 4 | 偏买入/等待确认 |
| 40–59 | 2.5 | 等待时机 |
| 60–79 | 1 | 持有/准备减仓 |
| 80–100 | 0 | 减仓区域 |

- **计算口径:** 读取`data.value`、`data.value_classification`和记录时间`data.timestamp`。以指数记录自身的时间为观测时间，统一转UTC，且须不晚于`as_of`；接口快照时间`status.timestamp`不参与筛选。指数≥80提示过热/减仓，指数≤19提示极度恐惧/买入机会。仅成功调用才标记实际Action名称。
- **数据有效期:** 指数须为0–100，记录时间不晚于`as_of`且距其≤48小时；必要字段无效、接口失败或无合格记录则`data_missing`。confidence按通用四档规则判定。
- **评分含义:** 本维最高5分，加权0.15，百分制贡献最高7.5；维度完整时综合分上限为92.5。情绪分只影响综合评分，不单独触发加减仓，但可作为买入、减仓、等待的信号参考。
