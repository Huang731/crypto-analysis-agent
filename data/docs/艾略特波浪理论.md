# 《艾略特波浪理论》加密货币分析知识库配置

> 来源：拉尔夫·纳尔逊·艾略特《艾略特波浪理论》
> 用途：将波浪理论的结构分析框架映射到加密货币市场分析，聚焦 [维度 05] 趋势与均线
> 核心指标：Trend（日线收盘、MA200、MA50、ADX(14)、+DI/−DI）
> 格式：原则 → 适用维度 → 如何解释 → 禁止如何使用

## 一、核心配置逻辑

艾略特波浪理论认为市场以可识别的波浪模式运行，5浪推动+3浪调整构成完整周期，斐波那契比率是波浪之间关系的核心度量。配置到加密知识库时，核心映射为：波浪结构提供趋势阶段路线图，MA200/MA50 确认趋势方向，ADX(14) 和 +DI/−DI 确认推动浪强度与方向，日线收盘确认波浪突破有效性。

## 二、知识库条目

### 原则一：市场以5浪推动+3浪调整的模式运行

**原则**：市场趋势以五浪推动结构（沿主趋势方向）和三浪调整结构（逆主趋势方向）交替运行，构成完整的市场周期。

**适用维度**：
- 加密市场大级别趋势结构识别
- BTC/ETH减半周期中的波浪结构分析
- 加密市场牛市/熊市阶段划分与趋势定位

**如何解释**：
波浪理论认为市场以8浪模式运行：5个推动浪沿主趋势方向运行，3个调整浪逆主趋势方向运行，这些波浪遵循特定的规则和斐波那契比率。波浪理论在不单独使用时最为强大，多重信号一致能将良好的设置转化为卓越的设置。映射到加密市场：比特币的四年减半周期与波浪理论的大级别结构有一定的吻合性。在日线级别，推动浪的确认需要 MA200/MA50 方向一致、ADX(14) > 25 且上升、+DI > −DI；调整浪的确认则需要 ADX 下降、+DI/−DI 频繁交叉或方向逆转。

**禁止如何使用**：
- 禁止将波浪计数作为精确预测工具，必须用 MA200/MA50、ADX、DI 交叉验证。
- 禁止在 ADX(14) < 20 时强行数浪并交易。
- 禁止忽略日线收盘，用盘中价格强行确认波浪突破。
- 禁止在加密市场的极端行情中强行套用波浪结构。

---

### 原则二：斐波那契比率是波浪之间关系的核心度量

**原则**：波浪之间的回撤和延伸遵循斐波那契比率（38.2%、50%、61.8%等），可用于预判调整幅度和趋势目标。

**适用维度**：
- 加密市场回调支撑位判断
- 波浪目标价位测算
- 加密市场趋势延续与反转的比率验证

**如何解释**：
高信赖度的第3浪进场条件包括：第2浪在61.8%斐波那契回撤位结束，该水平与先前支撑位重合，上升的移动平均线与同一区域交会，RSI从超卖区转向上行显示动能转向。映射到加密市场：斐波那契回撤位在加密市场中被广泛使用，BTC和ETH的价格走势在关键斐波那契水平附近往往出现明显的支撑或阻力反应。当斐波那契回撤位与 MA50 或 MA200 交汇，且 ADX(14) 上升、+DI/−DI 方向一致时，入场区域可靠性更高。

**禁止如何使用**：
- 禁止将斐波那契比率视为精确的价格预测，斐波那契水平是概率区域。
- 禁止在加密市场中选择过多的斐波那契回撤位。
- 禁止忽略加密市场流动性对斐波那契水平有效性的影响。
- 禁止在 ADX(14) < 20 时依赖斐波那契回撤位作为独立入场依据。

---

### 原则三：波浪理论与均线系统结合可提高趋势判断精度

**原则**：波浪理论提供趋势结构路线图，MA200/MA50 和 ADX/DI 确认趋势方向和强度，两者结合可提高分析可靠性。

**适用维度**：
- 加密市场波浪结构与均线方向的交叉验证
- 加密市场第4浪回调买点识别
- 加密市场趋势加速与衰竭阶段的判断

**如何解释**：
在趋势中，第4浪常在上升的移动平均线处反弹。艾略特波浪提供路线图，其他工具确认精确的转折点。可整合的工具包括支撑与阻力、动量指标、移动平均线和成交量。映射到加密市场：在BTC的上升趋势中，第4浪回调往往在 MA50 或 MA200 附近获得支撑。此时结合斐波那契回撤位、MA50/MA200 位置、ADX(14) 是否维持 > 25、+DI 是否仍 > −DI，可判断入场区域。

**禁止如何使用**：
- 禁止在均线方向与波浪结构方向相反时进行交易。
- 禁止过度复杂化分析，两到三个一致的工具胜过十个相互矛盾的工具。
- 禁止忽略加密市场不同时间周期的波浪结构可能相互矛盾。
- 禁止在 ADX(14) < 20 时将波浪结构与均线交叉作为交易依据。

## 三、维度 05 覆盖说明

**趋势识别**：波浪结构提供趋势的阶段定位（推动浪/调整浪），MA200/MA50 和 ADX/DI 提供趋势方向和强度的量化确认。
**均线应用**：第4浪在 MA50 或 MA200 处反弹是波浪理论与均线结合的核心应用。
**局限**：波浪计数的主观性和加密市场定价历史的短暂性，使波浪理论在加密市场中的应用需要 MA200/MA50、ADX、+DI/−DI 的交叉验证。
